# Router-on-a-stick subinterface addressing example
# Project networks documented for R1. Check the current running configuration
# before applying any commands to avoid replacing working configuration.

interface gigabitEthernet0/0
 no shutdown
!
interface gigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
!
